```echo 'export XILINXD_LICENSE_FILE=2100@e3c-lic.u-aizu.ac.jp' >> ~/.bashrc```  
|パーツ        役割・意味  
echo '...'|    シングルクォーテーションで囲まれた文字列を画面に出力（表示）するコマンド。  
>>  |          出力先を「画面」ではなく**「ファイルの末尾に追記する」**という記号（リダイレクト）。  
~/.bashrc   |  ユーザーのホームディレクトリにある、シェル（ターミナル）を起動するたびに自動実行される設定ファイル。  
つまり、全体の動きとしては以下のようになります。  
「~/.bashrc という設定ファイルの最後に、export XILINXD_LICENSE_FILE=2100@e3c-lic.u-aizu.ac.jp という設定値を追加して保存してね」  
  
このコマンドは、「Linuxの環境設定ファイルに、Xilinx（ザイリンクス）製ツールのライセンスサーバーの場所を登録する」という意味です。  
エンジニアっぽく言うと「ログイン時に自動でライセンスが通るように設定している」状態になります。  

```XILINXD_LICENSE_FILE```
- FPGA開発などで使われる Xilinx（現AMD）のツール（Vivadoなど）が、「ライセンスはどこにある？」と探しにいく環境変数（設定の引き出し）の名前です。

```2100@e3c-lic.u-aizu.ac.jp```
- ライセンスサーバーの住所です。
- ```2100```：通信に使うポート番号
- ```e3c-lic.u-aizu.ac.jp```：会津大学内にあるライセンスサーバーのホスト名
  
  
環境情報  
- windows11
- commandprompt
- used wi-fi:ains-wifi
  
```ping``` コマンドで```e3c-lic.u-aizu.ac.jp```サーバーに接続できるかを確認する  
確認できたら  
自分のコンピュータでこのコマンドを実行  
```setx XILINXD_LICENSE_FILE "2100@e3c-lic.u-aizu.ac.jp"```  
- やっていること：Windows の「ユーザー環境変数」に、ライセンスサーバーの場所を永久に保存しています。
- 目的：これを行うことで、コマンドプロンプトを閉じたりPCを再起動したりした後でも、Vivado などの Xilinx 製ツールが自動的に大学のライセンスを見つけて起動できるようになります。
  
```set``` と ```setx``` の違い
- 通常の set コマンドはその時開いている黒い画面（プロンプト）を閉じると消えてしまいますが、setx を使うと Windows 自体に設定が保存されます。
  
  
設定したライセンス情報の削除  
```reg delete HKCU\Environment /v XILINXD_LICENSE_FILE /f```  
- 解説：setx で保存された設定は Windows の「レジストリ」という場所に書き込まれるため、それをピンポイントで削除するコマンドです。
- 注意：削除した後は、一度コマンドプロンプトを閉じて開き直すか、PCを再起動すると完全に反映されます。
